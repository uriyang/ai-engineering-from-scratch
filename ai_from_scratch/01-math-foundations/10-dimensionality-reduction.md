# 차원 축소

차원 축소는 많은 특징을 더 적은 차원으로 줄이면서, 데이터의 중요한 구조는 최대한 남기는 방법이다. 고차원 데이터는 보기 어렵고 계산도 무거워서, 머신러닝에서는 자주 차원 축소를 쓴다.

## 고차원 공간의 문제

- 차원이 커지면 점 사이의 거리가 비슷해져서 가까운 점을 찾기 어려워진다.
- 데이터가 공간 전체에 골고루 퍼지기보다 가장자리 쪽으로 몰린다.
- 필요한 데이터 양도 급격히 늘어난다.

즉, 차원이 높을수록 데이터는 보기 어렵고, 모델은 더 많은 데이터를 필요로 한다.

## PCA

PCA(주성분 분석)는 데이터가 가장 많이 변하는 축을 찾는 방법이다.

흐름은 간단하다.
1. 데이터를 평균 0이 되게 중심을 맞춘다
2. 공분산 행렬을 구한다
3. 고유값과 고유벡터를 찾는다
4. 분산이 큰 방향부터 고른다
5. 필요한 개수만 남기고 나머지는 버린다

쉽게 말하면:
- 데이터가 가장 많이 변하는 방향을 새 축으로 잡는다
- 그중 중요한 축만 남기고 나머지를 줄인다

## 설명된 분산

- 각 주성분이 전체 분산의 얼마를 설명하는지 보여준다
- 누적 설명 비율이 높을수록 정보 손실이 적다
- 보통 90%~95% 정도를 기준으로 차원 수를 고른다

## t-SNE와 UMAP

- t-SNE는 가까운 점끼리 이웃으로 보이게 만드는 데 강하다
- UMAP은 비슷한 목적을 가지면서 더 빠르고, 전체 구조도 조금 더 잘 보존한다
- 둘 다 주로 2D나 3D 시각화에 쓴다

간단히 말하면:
- PCA는 압축과 전처리에 좋다
- t-SNE와 UMAP은 구조를 눈으로 보는 데 좋다

## 언제 무엇을 쓸까

- PCA는 전처리나 데이터 압축에 쓴다
- t-SNE는 작은 데이터의 2D 시각화에 쓴다
- UMAP은 더 큰 데이터의 2D 시각화에 쓴다
- kernel PCA는 선형 PCA로는 잘 안 보이는 비선형 구조를 볼 때 쓴다

정리하면:
- PCA는 빠르고 정확해서 먼저 시도하기 좋다
- t-SNE와 UMAP은 눈으로 구조를 확인할 때 좋다
- kernel PCA는 데이터가 휘어 있거나 원형 구조를 가질 때 도움이 된다

## kernel PCA

kernel PCA는 선형 PCA로는 잘 안 되는 비선형 구조를 다룬다.

- 원래 공간에서는 직선으로 나누기 어려운 데이터도
- 커널 함수를 통해 더 높은 차원에서 보면 잘 분리될 수 있다

대표적인 예:
- 동그란 점들이 겹쳐 있는 데이터
- 이런 경우 일반 PCA로는 잘 안 풀린다
- RBF 커널을 쓰면 구조가 더 잘 드러난다

## 재구성 오류

- 차원을 줄였으면 얼마나 잃었는지도 봐야 한다
- 재구성 오류는 줄인 뒤 다시 복원했을 때의 차이이다
- 오류가 작을수록 원래 정보를 잘 보존한 것이다

재구성 오류를 주성분 개수에 대해 그래프로 그리면 보통 `팔꿈치` 모양이 나온다.
- 곡선이 평평해지면 더 늘려도 얻는 이득이 작아진다
- 누적 분산이 0.90이나 0.95 같은 임계값을 넘는 지점이 자주 쓰인다
- 아래 작업의 성능이 더 좋아지지 않기 시작하면 그 지점에서 멈춘다

PCA에서는 설명된 분산과 재구성 오류가 연결된다.
- 설명된 분산이 높을수록
- 잃은 정보는 적다

## 한 줄 요약

차원 축소는 고차원 데이터에서 중요한 구조만 남기고 나머지를 줄이는 방법이며, PCA가 가장 기본적인 출발점이다.
