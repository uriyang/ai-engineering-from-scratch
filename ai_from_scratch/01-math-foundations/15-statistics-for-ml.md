# 통계와 머신러닝

> 통계는 모델이 진짜 좋아진 건지, 그냥 운이 좋았던 건지 구분하게 해준다.

## 통계란 무엇인가

통계는 데이터를 요약하고, 변수 사이의 관계를 보고, 결과가 우연인지 아닌지 판단하는 도구이다. 평균, 분산, 상관관계, 가설 검정, 부트스트랩이 모두 여기에 들어간다.

머신러닝에서는 통계가 필수다. 점수 하나만 보고 모델을 판단하면, 실제로는 노이즈를 성능으로 착각하기 쉽다.

## 기술통계

기술통계는 데이터를 몇 개의 숫자로 압축하는 방법이다. 데이터의 중심과 퍼짐을 먼저 봐야 다음 분석이 흔들리지 않는다.

### 중심 경향 측정값

- 평균은 모든 값을 더해 개수로 나눈 값이다.
- 중앙값은 정렬했을 때 가운데 값이다.

```text
mean = (1/n) * sum(x_i)
median = sorted values의 가운데 값
```

평균과 중앙값이 크게 다르면 분포가 비대칭적이라는 뜻이다. 소득 분포는 억만장자들 때문에 평균이 중앙값보다 훨씬 클 수 있고, 학습 과정의 손실 분포는 쉬운 샘플이 많아서 평균이 중앙값보다 작을 수 있다.

### 분산

- 분산은 평균에서 얼마나 퍼져 있는지를 본다.
- 표준편차는 분산의 제곱근이다.
- 범위는 최댓값과 최솟값의 차이다.
- 사분위범위(IQR)는 가운데 50%의 퍼짐을 본다.

```text
variance = (1/n) * sum((x_i - mu)^2)
std = sqrt(variance)
IQR = Q3 - Q1
```

### 백분위수

백분위수는 정렬한 데이터에서 어느 위치에 있는지를 보여준다. P95는 값의 95%가 그 아래에 있다는 뜻이다. 지연 시간이나 오류 분포에서는 평균보다 백분위수가 더 중요할 때가 많다.

### 표본과 모집단 (베셀의 보정)

표본의 분산은 보통 `n` 대신 `n-1`로 나눈다. 이것이 베셀 보정이다. 표본 평균이 모집단 평균을 완벽하게 대신하지 못하는 편향을 줄여준다.

## 상관관계

상관관계는 두 변수가 얼마나 함께 움직이는지를 본다.

### 피어슨 상관계수

피어슨 상관계수는 선형 관계를 측정한다.

```text
r = sum((x_i - x_bar)(y_i - y_bar)) / (n * s_x * s_y)
```

- `+1`이면 완전한 양의 선형 관계
- `-1`이면 완전한 음의 선형 관계
- `0`이면 선형 관계가 없다는 뜻이다

피어슨은 선형 관계에 강하지만 비선형 관계는 놓칠 수 있다. 이상치에도 민감하다.

### 스피어만 상관계수

스피어만 상관계수는 순위를 이용해 단조 관계를 본다. 값의 크기보다 순서가 중요할 때 잘 맞는다.

```text
1) 값을 순위로 바꾼다.
2) 순위에 대해 Pearson correlation을 계산한다.
```

- 순위 데이터
- 비정규 분포
- 비선형이지만 한 방향으로만 변하는 관계

### 상관관계와 인과관계 (황금률)

상관관계가 있다고 해서 원인과 결과가 있다는 뜻은 아니다. 여름에는 아이스크림 판매량과 익사 사고가 함께 늘지만, 하나가 다른 하나의 원인은 아니다.

## 공분산 행렬

공분산은 두 변수가 함께 어떻게 움직이는지를 본다. 공분산 행렬은 모든 특징쌍의 공분산을 한 번에 담은 행렬이다.

```text
Cov(X, Y) = (1/n) * sum((x_i - x_bar)(y_i - y_bar))
```

- 대각선은 각 특징의 분산이다.
- 비대각선은 특징들 사이의 공분산이다.
- 대칭 행렬이다.
- PCA와 마할라노비스 거리의 기반이다.

공분산 행렬은 데이터의 전체 구조를 요약한다. PCA는 이 행렬을 분해해서 분산이 큰 방향을 찾는다.

## 가설 검정

가설 검정은 어떤 주장에 대해 데이터가 그 주장을 지지하는지 확인하는 방법이다.

- 귀무가설 `H0`: 차이 없음, 효과 없음이라는 기본 가정
- 대립가설 `H1`: 확인하고 싶은 주장

```text
p-value = P(data this extreme | H0 is true)
```

p-value는 귀무가설이 참일 때 지금처럼 극단적인 데이터를 볼 확률이다. p-value가 작다고 해서 귀무가설이 참일 확률이 작은 것은 아니다.

```text
95% CI for the mean = x_bar +/- 1.96 * (s / sqrt(n))
```

신뢰구간은 어떤 값이 들어 있을 법한 범위를 보여준다. 구간이 좁을수록 추정이 더 정밀하다.

## t-검정

t-검정은 평균이 다른지 확인할 때 쓴다.

- 단일 표본 t-검정: 평균이 기준값과 다른가?
- 두 표본 t-검정: 두 집단의 평균이 다른가?
- 대응 표본 t-검정: 같은 대상의 전후를 비교할 때

머신러닝에서는 같은 테스트 셋에서 두 모델의 성능을 비교할 때 자주 쓴다.

```text
one-sample t = (x_bar - mu_0) / (s / sqrt(n))
paired t는 d_i = x_i - y_i에 대해 one-sample t를 적용한다.
```

## 카이제곱 검정

카이제곱 검정은 관측된 빈도와 기대 빈도가 다른지 본다. 범주형 데이터에 잘 맞는다.

```text
chi^2 = sum((observed - expected)^2 / expected)
```

- 클래스 분포가 예상과 다른가
- 범주별 출력 분포가 바뀌었는가
- 독립이라고 가정한 변수들이 실제로도 독립인가

## A/B 테스트

모델을 비교할 때는 단순히 점수만 보는 것보다 같은 데이터에서 비교하고 변동성까지 보는 것이 중요하다.

실무에서는 다음을 확인한다.

- 같은 테스트 셋을 썼는가
- 여러 지표를 함께 봤는가
- 교차 검증이나 부트스트랩으로 분산을 추정했는가
  - 교차 검증: 데이터를 여러 번 나눠서 평가하는 방법
  - 부트스트랩: 데이터를 복원 추출로 여러 번 다시 뽑아 평가하는 방법
- 데이터 누수가 없었는가
- 통계적으로 유의한지와 실제로 의미 있는지를 둘 다 봤는가

```text
d_i = b_i - a_i
Cohen's d = (mean_1 - mean_2) / pooled_std
```

## 통계적 유의성과 실용적 유의성

통계적으로 유의하다는 것은 우연으로 보기 어렵다는 뜻이다. 하지만 실제로 중요한 차이라는 뜻은 아니다.

아주 큰 데이터에서는 미세한 차이도 쉽게 유의해진다. 그래서 p-value만 보지 말고 효과 크기도 같이 봐야 한다.

- p-value는 차이가 우연인지 아닌지를 본다.
- 효과 크기는 차이가 얼마나 큰지를 본다.

## 다중 비교 문제

여러 가설을 동시에 검정하면 우연히 유의한 결과가 나올 가능성이 커진다. 그래서 보정이 필요하다.

대표적인 방법은 본페로니 보정이다. 유의수준을 검정 개수로 나눠 false positive(오탐)를 줄인다.

## 부트스트랩

부트스트랩은 데이터를 복원 추출로 여러 번 다시 뽑아 통계량의 분포를 추정하는 방법이다. 분포를 가정하지 않아도 되고, 거의 모든 지표에 쓸 수 있다.

```text
95% CI = [2.5th percentile, 97.5th percentile]
```

머신러닝에서는 다음에 특히 유용하다.

- 정확도나 F1의 신뢰구간을 구할 때
- 두 모델의 차이에 대한 신뢰구간을 구할 때
- 정규 분포를 가정하기 어려운 지표를 다룰 때

## 모수 검정과 비모수 검정

모수 검정은 특정 분포를 가정한다. 비모수 검정은 그런 가정을 거의 하지 않는다.

- t-검정, ANOVA, Pearson 상관계수는 모수 검정 계열이다.
- Mann-Whitney U, Wilcoxon, Spearman은 비모수 검정 계열이다.

표본이 작거나 분포가 많이 치우쳐 있으면 비모수 검정이 더 안전할 수 있다.

## 중심극한정리

중심극한정리는 표본 평균의 분포가 표본 수가 커질수록 정규분포에 가까워진다는 내용이다.

```text
X_bar ~ Normal(mu, sigma^2 / n)
```

머신러닝에서는 이 성질 덕분에 다음이 가능하다.

- 교차 검증 점수의 평균을 안정적으로 해석하기
- 배치 평균 gradient로 전체 경향을 근사하기
- 신뢰구간과 t-검정을 쓰기

## ML에서 자주 하는 통계 실수

- 학습 데이터로 테스트하기
- 신뢰구간 없이 점수 하나만 보고 판단하기
- 여러 실험을 해놓고 좋은 결과만 고르기
- 통계적 유의성과 실용적 유의성을 혼동하기
- 불균형 데이터에서 accuracy만 보기
- 데이터 누수를 만들기
- 아주 작은 테스트셋으로 큰 개선이라고 주장하기

## 왜 중요한가

통계는 모델이 잘 학습됐는지, 성능 차이가 진짜인지, 결과를 어디까지 믿어도 되는지를 알려준다. 머신러닝에서 통계가 없으면, 우리는 모델을 평가하는 게 아니라 운을 해석하게 된다.
